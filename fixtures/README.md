# PlayoutTranscode V2-0 Fixtures Directory

This directory contains fixture metadata, instructions, and test media generated for baseline verification of `PlayoutTranscode`.

## Files in this directory

- `README.md` (this file): Directory overview and instructions.
- `manifest.json`: Canonical metadata specification for all test fixture classes, probe expectations, profile classifications, and status assertions.
- `*.mp4`, `*.mp3`, `*.mkv` (generated): Synthetic media files generated by `scripts/generate-fixtures.ps1`.

## Generating Fixtures

Do not manually add binary media files to Git. Run the PowerShell generation script:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/generate-fixtures.ps1
```

Requirements:
- `ffmpeg` and `ffprobe` must be installed on PATH or placed in `bin/` (or downloaded via the PlayoutTranscode control panel).
- If FFmpeg/FFprobe binaries are missing, `generate-fixtures.ps1` will fail clearly with exit code `1`.

## Running Verification

To verify that generated media fixtures match expected normalized probe properties and contract classifications:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/verify-baseline.ps1
```

Verification assertions include:
- Duration in milliseconds
- Resolution (width and height)
- Rational frame rates (`fps_num`, `fps_den`)
- Audio stream properties (sample rate, channel count, codec)
- Profile selection mapping (Profile A vs Profile B vs Profile C)
- Informational SHA-256 calculation for auditability
